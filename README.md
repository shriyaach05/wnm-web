# WnM — Weather 'n' Movies

A small web app that shows live weather for any city and lets you search movies.
Built with plain HTML, CSS, and JavaScript.

## What it does

- **Home** — greeting, date, and two big cards to jump into Weather or Movies
- **Weather** — live current conditions, hourly forecast, and 7-day forecast for any city
- **Location** — save cities, see their live temperatures, edit or remove them
- **Movies** — search any movie, see a grid of results, click one for details
